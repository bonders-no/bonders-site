# Bonders Tjenester

Starter website for Cloudflare Workers.

## Local preview
1. Install Node.js.
2. `npm install`
3. `npm run dev`

## Deploy
Use `npm run deploy` or connect the GitHub repository to Cloudflare Workers Builds.

## Optional Telegram notifications
Add these Cloudflare secrets:
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

Before publishing, replace `+47XXXXXXXX` in `public/index.html` with your phone number.
